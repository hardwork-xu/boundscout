# 预先冻结的实验协议

2026-09-21 在引擎实现与计时前冻结。修改须追加原因并保留原目标。

## 问题与范围

空间分块与保守包围盒距离下界，能否以适当建索引及查询成本减少 CPU 精确 top-k 检索的计算量？贡献是可审阅实现与可核查实验，并非新的最近邻算法。目标用户是研究离线特征向量精确检索的维护者。不涉及 GPU、近似召回率取舍、嵌入模型、可变索引、分布式服务或生产级声明。

## Target：目标，非实测

主要目标：对 32,768 个 32 维聚类向量、64 个留出查询、k=10、叶块 256、16 个簇、中心尺度 8、簇内标准差 0.5，相比有界内存 SciPy `cdist` 穷举，稳态查询批次中位数加速至少 **1.50 倍**，距离计算向量数减少至少 **75%**。双方使用 float64 和单原生线程。未达性能目标不影响如实交付。

正确性要求：与按 `(平方距离, 原始行 ID)` 排序的穷举具有相同 ID 顺序，距离容差 `rtol=1e-12, atol=1e-12`。拒绝非有限输入。辅助指标：建索引、保存、加载时间，查询批次中位数及最小/最大值，吞吐量，计算向量数，索引数组字节数，隔离进程峰值 RSS，以及建索引摊销点。逻辑数组字节数与进程 RSS 分开记录。

## 基线与消融

实用基线：SciPy 已编译平方欧氏距离 `cdist`，按 256 行分块并部分选取 top-k。附加基线：SciPy `cKDTree`，eps=0、workers=1；等距 ID 顺序可能不同，比较有序距离。消融：同一空间索引关闭剪枝；按输入顺序分块开启剪枝。各方法完成同样的 top-k 工作。增加大块穷举基线，披露小块循环开销。

## 工作负载与测量

合成聚类和各向同性高斯向量，N=4,096/32,768，维度 8/32/128，按配置覆盖 k=1/10/100；如能成功下载，增加公开真实词向量。正确性测试覆盖高维不利场景、重复点及分布外查询。独立种子 20260921、20260922；完整矩阵在计时前写入 configs。各方法先预热一次，再进行七次查询批次计时，每轮以固定种子打乱方法顺序。另计建索引后的首次查询；无 JIT。下载、预处理、建索引单独计时，不计入稳态查询。不宣称模型或服务端到端性能；七个批次不足以报告 p99。保留全部有效样本，失败另行记录。

离线 pytest、CLI、索引存储往返、干净隔离安装、Ruff、mypy、包构建、带源码指纹及命令的原始实验数据、自动生成双语表格和图表、双语维护发布材料、隐私审查及真实本地提交。Docker 可用时实际执行，否则标记未运行。远端 CI 只有实际执行后才能记为通过。用户末尾指令授权公开发布，须先完成隐私审查。
